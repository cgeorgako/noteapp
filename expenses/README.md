# 💶 Έξοδα — Καταγραφή εξόδων (web app)

Απλή εφαρμογή σε ένα αρχείο HTML για την καταγραφή των μηνιαίων εξόδων ανά κατηγορία.

## Χαρακτηριστικά

- **Καταχώρηση με φωνή** (μικρόφωνο, μέσω Web Speech API του Chrome). Πες π.χ.
  «σούπερ μάρκετ 35 ευρώ» ή «καφές 4» και καταχωρείται αυτόματα, με αναγνώριση
  κατηγορίας από λέξεις-κλειδιά.
- **Χειροκίνητη φόρμα** με ποσό, κατηγορία, περιγραφή και ημερομηνία.
- **Πάγια (επαναλαμβανόμενα) έξοδα**: όρισέ τα μία φορά (ενοίκιο, ρεύμα,
  συνδρομές…) και με ένα κλικ «Εφαρμογή παγίων στον μήνα» προστίθενται στον
  τρέχοντα μήνα (χωρίς διπλοεγγραφές).
- **Σύνολα ανά μήνα** και **ανάλυση ανά κατηγορία** με ποσοστά και μπάρες.
- **Πλοήγηση μήνα** (◀ ▶) για να βλέπεις/καταχωρείς σε οποιονδήποτε μήνα.
- **Τοπική αποθήκευση** στον browser (localStorage) — δεν φεύγει τίποτα στο
  διαδίκτυο.
- **Αντίγραφο ασφαλείας**: Εξαγωγή/Εισαγωγή αρχείου `.json` (π.χ. για ανέβασμα
  στο Google Drive ή μεταφορά σε άλλη συσκευή).
- Φωτεινό/σκοτεινό θέμα.

## Χρήση

Για να δουλέψει το **μικρόφωνο**, η σελίδα πρέπει να ανοίξει σε **Chrome** μέσω
`https://` ή `localhost` (όχι από διπλό-κλικ `file://`).

Γρήγορος τοπικός server:

```bash
cd expenses
python3 -m http.server 8000
# άνοιξε http://localhost:8000 στο Chrome
```

Στο κινητό: άνοιξέ το στο Chrome, δώσε άδεια μικροφώνου, και προαιρετικά
«Προσθήκη στην αρχική οθόνη» για να λειτουργεί σαν εφαρμογή.

## Σημειώσεις

- Η φωνητική αναγνώριση χρησιμοποιεί την τεχνολογία φωνής της Google μέσα στο
  Chrome. Δεν είναι ενσωμάτωση «Google Assistant» (που θα απαιτούσε ξεχωριστό
  project *Actions on Google*), αλλά καλύπτει το ίδιο σενάριο: μιλάς και
  καταγράφεται το έξοδο.
- Τα δεδομένα είναι τοπικά ανά συσκευή/browser. Για συγχρονισμό χρησιμοποίησε
  την Εξαγωγή/Εισαγωγή (π.χ. μέσω Google Drive).
